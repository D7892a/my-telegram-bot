مساعد الدعم الذكي

يقترح رداً أولياً على الرسالة، وإذا لم يجد حلاً ينشئ تصعيداً للإدارة للمحادثة المباشرة.

المساعد تجريبي حالياً ويحتاج ربط API ذكاء اصطناعي آمن على الخادم قبل التشغيل الفعلي.

قاعدة البيانات (Firebase)

البيانات مخزّنة في Cloud Firestore وتتزامن لحظياً بين كل الأجهزة، مع نسخة محلية للعمل بدون إنترنت.

القاعدة السحابية غير مهيأة بعد. افتح صفحة setup.html لتهيئة البيانات وحساب الإدارة.
