# دجلة رايد 🚕

نسخة أولية متكاملة لخدمة حجز التكسي داخل الناصرية، بواجهة عربية متجاوبة.

## المزايا

- إنشاء حساب زبون بالاسم ورقم الهاتف وكلمة سر مشفرة.
- تسجيل دخول وخروج وربط الرحلات بصاحب الحساب.
- واجهة راكب مع خريطة تفاعلية لاختيار الانطلاق والوجهة.
- حساب تلقائي للمسافة والأجرة لثلاث فئات سيارات.
- **سجل رحلاتي**: الزبون يشوف كل رحلاته مع حالتها، يلغي الطلب قبل انطلاق الكابتن، ويقيم الرحلة بنجوم وملاحظة بعد اكتمالها.
- **ملف الكابتن الحي**: أرباح اليوم، عدد الرحلات، كل الأرباح، وآخر تقييمات الركاب، مع تحديث متوسط التقييم تلقائياً بعد كل تقييم.
- تقديم طلب سائق مع الهوية، إجازة السوق، سنوية السيارة والصورة الحية.
- حفظ المستمسكات في مساحة خاصة لا يستطيع الزوار فتحها.
- واجهة كابتن لقبول الطلب وتحديث مراحل الرحلة بعد موافقة الإدارة.
- لوحة مستقلة لمالك التطبيق على `/owner` لمراجعة المستمسكات وقبول أو رفض السائقين.
- لوحة إدارة تعرض الرحلات والإيرادات اليومية، رسم بياني لحركة آخر 7 أيام، وأفضل الكباتن.
- إشعار اختياري للسائقين عن طريق Telegram.
- قاعدة بيانات SQLite تُنشأ تلقائياً.

## التشغيل محلياً

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

ثم افتح `http://localhost:8080`.

## متغيرات البيئة الاختيارية

| المتغير | الاستخدام |
|---|---|
| `PORT` | منفذ الموقع، الافتراضي `8080` |
| `BOT_TOKEN` | توكن بوت Telegram |
| `DRIVER_CHAT_ID` | رقم المجموعة أو المحادثة التي تستقبل الطلبات الجديدة |
| `SECRET_KEY` | مفتاح طويل وعشوائي لحماية جلسات تسجيل الدخول |
| `ADMIN_PHONE` | رقم دخول مالك التطبيق |
| `ADMIN_PASSWORD` | كلمة سر مالك التطبيق |

للتجربة المحلية فقط، حساب الإدارة الافتراضي هو `07800000000` وكلمة السر `Admin123!`. **يجب** ضبط `ADMIN_PHONE` و`ADMIN_PASSWORD` و`SECRET_KEY` بقيم قوية قبل نشر الموقع.

بدون متغيرات Telegram يعمل الموقع بصورة طبيعية، لكن لن يرسل إشعارات إلى السائقين.

## النشر

المشروع يحتوي على `Procfile` وجاهز للنشر على Render أو خدمة تدعم تطبيقات Flask. قبل الاستخدام التجاري الفعلي يجب نقل قاعدة البيانات إلى PostgreSQL، ونقل المستمسكات إلى تخزين خاص ودائم مثل S3 مع تشفيرها، لأن قرص الخدمة المؤقت لا يصلح لحفظ وثائق الهوية.
